04 / Method and limits

A research demonstrator, not an emergency product.

The pipeline is the dataset's, not an approximation of it. Sentinel-2 COPERNICUS/S2_SR_HARMONIZED surface reflectance, bands B12/B8/B4 with Cloud Score+ cs_cdf linked per scene, granules of one overpass mosaicked by datatake, DN clamped to 0–5000, and a 20 m grid in the scene's local UTM zone. Every preprocessing constant is read at page load from model/model_meta.json, which the export script writes from the training code, so the browser cannot drift away from the research path. scripts/verify_browser_pipeline.py checks this implementation against the reference one on a real tile.

The pre-fire scene comes from the previous year's fire season, not from the weeks before ignition. That is how the model was trained — the dataset searches the fire's own date window shifted back one year — and it is what controls for phenology while avoiding the smoke-filled active-fire period. Set the pre-fire date inside that prior-year season; a date one year before the target observation is not the same thing, and for a fire observed long after it stopped burning it can miss the season by months. Each preset carries the date the dataset loader itself selected for that fire. Both scenes are then chosen by clarity — highest mean cs_cdf minus the no-data fraction — which is the loader's own rule.

cs_cdf is a model input, not a mask. The network is given the clear score as a fourth channel per phase, so it knows which pixels it cannot trust rather than having to infer that from brightness. Pixels either phase could not see through, below cs_cdf 0.65, are then reported as obscured and excluded from the area — this product does not score an unobserved pixel as unburned. Imagery is displayed with cloud left in, because masking it to grey fills a panel with holes that read as lakes rather than as weather.

Two windows, because the model has two scales. The orange box is segmented at 20 m in overlapping 256 px patches, Gaussian-blended, with components under 50 px dropped. The dashed box is what the tile context encoder sees, compressed to 256 px; it was 35–154 km in training, which is why it is set much larger than the detail window and why shrinking it moves the result.

What it does not do. It segments burning already visible in the target image; it does not predict ignition or future spread. It was trained on Canada 2017–2023, validated on 2024 and tested on 2025. Cloud, smoke, snow, misregistration, unfamiliar ecosystems and imagery outside those years can all cause errors — the Kalimantan preset is deliberately out of domain, and while that result is corroborated by dNBR there is no burned-area reference for it.
