One-time setup — you need your own Earth Engine access

This page has no server and no credentials of its own: it runs on your Google account and your Earth Engine project. Both fields above are yours to fill, once; the browser remembers them afterwards.

  1. Have a Google Cloud project with the Earth Engine API enabled and registered for Earth Engine. Put its project ID in the first field.
  2. In that project, under APIs & Services → Credentials, create an OAuth 2.0 client of type Web application.
  3. Add this site's origin — scheme and host only, no path, no trailing slash — to its Authorized JavaScript origins. Without this, Google refuses the sign-in.
  4. Paste the client ID, the value ending .apps.googleusercontent.com, into the second field. A client ID is public configuration. Never paste the client secret (it starts GOCSPX-) or a service-account key — this page does not use either.
  5. If Google answers "has not completed the Google verification process", your consent screen is in Testing: add the account you sign in with under Audience → Test users. Keep it in Testing — publishing a sensitive scope triggers a manual review that takes weeks and buys nothing here.
  6. The one permission requested is earthengine.readonly. Earth Engine charges the pixel computation to the project you named; the model itself runs on this machine.
