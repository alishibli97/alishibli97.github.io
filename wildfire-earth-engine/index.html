01 / Connection

Connect Earth Engine

Not connected
One-time setup — about five minutes, and you only do it once

This page has no server and no credentials of its own: it runs on your Google account and your Earth Engine project. The two fields above are yours to fill in once; the browser remembers them afterwards. Each step below links to the exact console page it refers to.

  1. Create or pick a Google Cloud project. console.cloud.google.com/projectcreate ↗
    Copy its project ID — the lowercase one, not the display name — into Google Cloud project above.
  2. Register that project for Earth Engine. code.earthengine.google.com/register ↗
    Pick noncommercial use if you qualify. Earth Engine access belongs to the project, not to your account, so this has to be the same project as step 1.
  3. Enable the Earth Engine API in it. API library → Earth Engine API ↗
  4. Set up the consent screen. Google Auth Platform → Overview ↗
    If the page says “Google Auth platform not configured yet”, press Get Started and fill in an app name, support email, audience and contact email. For the audience choose External, unless your account is in a Google Workspace organisation and everyone using the page is too.
  5. Add yourself as a test user and stay in Testing. Google Auth Platform → Audience ↗
    Under Test users, press Add users and enter the Google account you will use. An Internal audience has no test-user list and needs none.
  6. Create an OAuth client of type Web application. Clients → Create client ↗
    Under Authorized JavaScript origins, add exactly this page’s origin — scheme and host, with no path or trailing slash.
  7. Paste the client ID into the second field above. It ends in .apps.googleusercontent.com. A client ID is public configuration. Never paste the client secret or a service-account key.
  8. Press Connect Google account.
    The requested permission is earthengine.readonly. Earth Engine computation uses your project; model inference runs in this browser, and no imagery or result is uploaded by this page.

04 / Important

A research demonstrator, not an emergency product.

The imagery pipeline mirrors the dataset: Sentinel-2 L1C harmonized SWIR2/NIR/Red, Cloud Score+ cs_cdf ≥ 0.60, reflectance clamped to 0–5000, and a 20 m output grid. It selects a clear daily mosaic near each requested date.

The output segments burning already visible in the current image. It does not predict ignition or future spread. Cloud, smoke, snow, misregistration, unfamiliar ecosystems, and imagery outside the training years can cause errors.
